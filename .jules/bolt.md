## 2024-07-05 - Avoid redundant database queries for cached Workspace Service
**Learning:** React's `cache` memoizes the promise returned by `getWorkspaceExperienceBySlug(slug)`. If we already have the `Organization` object (e.g. from `selectMembershipOrganization` or `organizations.findFirstByWorkspaceEmailDomain`), calling `getWorkspaceExperienceBySlug(slug)` creates a redundant database query in `organizations.findBySlug(slug)` since we just fetched it.
**Action:** When the application layer already holds the `organization` object, bypass `getWorkspaceExperienceBySlug` and call `compileWorkspaceExperience({ slug, organization })` synchronously to save an unnecessary database query. Ensure that we don't access `compiled.organization` as `CompiledWorkspaceExperience` does not return the `organization` property.
