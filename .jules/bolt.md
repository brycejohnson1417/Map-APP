## 2024-10-08 - Avoid Redundant Async Fetching for Workspace Compiler
**Learning:** The `resolveTenantAccess` function frequently resolved the `Organization` object using `findBySlug` or similar repository methods, and immediately passed the slug to `getWorkspaceExperienceBySlug`. Because `getWorkspaceExperienceBySlug` internally re-fetches the same `Organization` object before calling the synchronous `compileWorkspaceExperience` compiler, this resulted in an unnecessary asynchronous database round-trip.
**Action:** When the full `Organization` object (containing `slug` and `settings`) is already present in the local execution context, completely bypass the wrapped asynchronous `getWorkspaceExperienceBySlug` method. Instead, invoke the internal `compileWorkspaceExperience` compiler directly by passing the pre-fetched `Organization` object, saving an expensive round-trip during the critical path of tenant resolution.
